### Changed

- `TRIAGE.md`'s builder-owned paragraph no longer assumes every builder session
  has the same boundary: a builder-owned criterion may require a named session
  capability, and where it does it says so in its own text — builder-owned and
  not operator-owned, the capability, and that a builder lacking it releases
  the claim (#575).
- The reach axis stays two-valued. A named capability is a property of the
  criterion, not a third owner class, so an issue whose criteria name one is
  builder-owned like any other (#575).
